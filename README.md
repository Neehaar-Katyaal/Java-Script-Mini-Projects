# Java-Script-Mini-Projects
### Drum Kit Project  

Developed an interactive Drum Kit web application using HTML, CSS, and JavaScript. Implemented keyboard and mouse event handling to play different drum sounds with real-time user interaction. Designed a responsive and visually engaging interface to improve user experience across devices.

### Simon Game Project  

Built a Simon Game web application using HTML, CSS, and JavaScript, featuring dynamic color patterns, sound effects, and increasing difficulty levels. Implemented game logic, user input handling, and sequence validation to create an interactive memory-based gaming experience with responsive design support.
